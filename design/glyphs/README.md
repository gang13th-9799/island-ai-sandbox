# Pictograph script (ศิลาความรู้)

Glyph stroke paths: `glyphs.json` (60×60 box). Number glyphs are keys `#0`–`#9`.

## Word-class marks (above the glyph)
| Mark | Class |
|---|---|
| — horizontal bar | noun |
| • dot | verb |
| ´ rising stroke | adjective |
| ` falling stroke | adverb |
| none | conjunction (และ หรือ แล้ว ถ้า), numbers, กลายเป็น |

"ไม่" = the ผิด glyph with the adverb mark.

## Writing order
- Left to right, lines top to bottom.
- Thai word order:
  - verb before its object: `มัด• หิน—`
  - number after the noun: `หิน— 2`
  - adjective after the noun: `หิน— ใหญ่´`
  - adverb after the verb: `เดิน• ขา`` → "walk fast"
  - ไม่ before the verb: `ไม่` ไฟ•` → "do not burn"
- Multi-digit numbers are written digit by digit, left to right.

## Examples
- `มัด• หิน— 2 ไม้— 1 เส้นใย— กลายเป็น เครื่องมือ—` = tie 2 stones and 1 wood with fiber, you get a tool.
- `ถ้า ไฟ• หิน— แล้ว หิน— ร้อน´` = if you burn the stone, the stone becomes hot.
