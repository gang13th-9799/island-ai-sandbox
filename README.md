# 🏝️ เกาะร้าง AI — Island AI Sandbox

เกมจำลองอารยธรรมที่ AI ทุกตัวเริ่มจากศูนย์ แล้วต้องเรียนรู้ เอาชีวิตรอด และสร้างสังคมขึ้นมาเอง
เล่นในเบราว์เซอร์ได้ทันที เป็นไฟล์เดียว และเซฟลงเครื่องแบบออฟไลน์

**▶️ เล่นเลย:** https://gang13th-9799.github.io/island-ai-sandbox/

## ระบบหลัก
- **เรียนรู้เอง** — ไม่มีสูตรสำเร็จ กฎธรรมชาติของแต่ละโลกถูกซ่อนไว้ AI ต้องทดลองที่สถานีงานจริง แล้วจดจำและสอนต่อกันเอง
- **ค่าสถานะแบบ MMORPG** — STR / AGI / VIT / INT / DEX / CHA เริ่มที่ 1 ทุกค่า และพรสวรรค์ S–D ของแต่ละตัวไม่เท่ากัน
- **สังคม** — มีเควสขอความช่วยเหลือ ต่อรองค่าตอบแทน ความสัมพันธ์ทั้งดีและร้าย ความเป็นเจ้าของ กระเป๋าส่วนตัว
- **หมู่บ้าน** — ประชุมรอบกองไฟ โหวตหัวหน้า ตกลงอัตราส่งของเข้าโกดัง (ถอนต้องเอาของมาแลก) แบ่งงาน และตั้งชื่อหมู่บ้านเอง
- **ระบบนิเวศ** — นักล่ากลัวไฟ สัตว์สู้แย่งอาณาเขต วิวัฒนาการ และกลายพันธุ์เมื่อกินธาตุ
- **กลับชาติมาเกิด** — พกความรู้ไปชาติหน้าได้ตามเลเวล ความลับชาติก่อนห้ามบอกใคร ไม่งั้นพระเจ้าจะลงทัณฑ์
- **หลายดินแดน** — 4 ดินแดนเดินเวลาพร้อมกัน ข้ามไปมาได้ผ่านเกจแห่งพระเจ้า ถ้าดินแดนไหนล่มสลาย พระเจ้าจะตามหาผู้กอบกู้

## 🕸️ กราฟความรู้ของโค้ด (Graphify)
ใช้ [graphify](https://github.com/safishamsi/graphify) ตัวจริงสร้างกราฟความรู้ของโค้ดเกม โดย GitHub Actions จะรันให้อัตโนมัติทุกครั้งที่ `index.html` เปลี่ยน (โหมดอ่านเฉพาะโค้ด ทำงานออฟไลน์ ไม่ต้องมี API key)
- `graphify-out/graph.html` — กราฟแบบโต้ตอบ: https://gang13th-9799.github.io/island-ai-sandbox/graphify-out/graph.html
- `graphify-out/GRAPH_REPORT.md` — สรุประบบหลัก จุดเชื่อมสำคัญ และคำถามแนะนำ
- `graphify-out/graph.json` — กราฟเต็ม

รันเองบนเครื่อง: `pip install graphifyy && python3 tools/split_source.py && cd graph-src && graphify extract . --code-only`
